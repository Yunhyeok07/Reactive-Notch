# Reactive Notch

갤럭시 탭 S9 Ultra의 카메라 노치를 다이내믹 아일랜드처럼 쓰는 안드로이드 앱입니다.

## 기능

- **노치 섬** – 실제 노치 위치·크기를 읽어서 노치 모양 그대로 늘어나는 섬. 가로 모드에서 노치가 위쪽에 있을 때만 동작하고, 세로 모드에서는 자동으로 꺼집니다.
- **음악** – 재생 중이면 노치 양옆에 앨범 아트와 파형, 탭하면 곡 정보·진행 바·이전/재생/다음.
- **이어폰 슬라이드** – 펼친 섬에서 옆으로 넘기면 이어폰 페이지(배터리, 소니 노이즈 캔슬). 대상: WH-1000XM6, WF-1000XM5.
- **제미나이** – 섬을 아래로 쓸어내리면 제미나이 앱(또는 기본 어시스턴트)을 실행.

## 설치

1. GitHub Actions의 `Build APK` 실행 결과에서 `reactive-notch-debug-apk` 를 받아 탭에 설치합니다 (또는 `./gradlew assembleDebug`).
2. 앱을 열고 안내대로 접근성 서비스, 알림 접근, 블루투스 권한을 허용합니다.
   직접 설치한 앱은 접근성 스위치가 회색일 수 있습니다. 앱 정보 → ⋮ → **제한된 설정 허용** 후 다시 시도하세요.

## 개발

```bash
./gradlew testDebugUnitTest assembleDebug
```

JDK 17, Android SDK 35 필요. 최소 Android 12 (API 31).

## 알려진 한계

- 접근성 서비스는 상태바/컷아웃 위에 오버레이를 그리기 위해서만 사용합니다. 화면 내용은 읽지 않습니다.
- **소니 프로토콜**: 프레임 구조(시작/끝 마커, 이스케이프, 체크섬, ACK)는 참조 구현과 대조해 테스트로 고정했지만, 배터리·노이즈 캔슬의 명령 번호와 응답 형식은 XM6/XM5 실기기로 검증되지 않은 추정값입니다(`bt/SonyProtocol.kt`의 `SonyCommands`). 설정 화면의 프로토콜 로그로 실제 응답을 확인해 고쳐야 합니다. 노이즈 캔슬은 그래서 기본 꺼짐입니다.
- 멀티 페어링(연결된 기기 목록)은 아직 구현되지 않았습니다. 명령을 확인할 수 없었기 때문입니다.
- Sony Headphones Connect 앱이 이미 헤드폰의 RFCOMM 채널을 잡고 있으면 연결이 거부될 수 있습니다.
- 파형 애니메이션은 실제 오디오 분석이 아니라 재생 상태에 맞춘 연출입니다.
